# Inventario Tercol 2026

Necesito que hagas una plataforma para el evento de inventario 2026 de la empresa Tercol SAS, este inventario se hace una vez cada 6 meses y la plataforma debe ser la encargada de gestionar los productos, cantidades y ubicaciones fisicas para ser contadas por el equipo. 

Desarrollarás una plataforma web para la gestión centralizada del inventario semestral. El sistema funciona como un gestor de tareas jerárquico donde la "Gran Tarea" (el inventario total) se fragmenta y delega en cascada a través de distintos roles. El objetivo es controlar la asignación, digitación (transcripción), consolidación y validación de conteos contra las tablas maestras del ERP.

Por ahora desarrolla una pagina de inicio con 3 vista de auth o login dividida en 2, a la izquierda 3 cards con los roles SuperAdmin, Administrador y Lider de Bodega. a la derecha haz el formulario de inicio de sesión y registro basico.

En la plataforma deberás usar la fuente inter y los colores rojos #b20000, #6b0000, #ffffff y #000000.

Usa componentes tipo glass en botones para que se vea moderna.
